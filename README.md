## Sobre o Projeto

A **PixelGear eSports Store** é uma página institucional e de vendas de uma startup focada em PCs Gamers de alta performance. 

Nesta evolução, a página deixou de ser apenas textual e passou a contar com imagens dos produtos em destaque e botões de **Call to Action (CTA)** interativos que direcionam o usuário para o WhatsApp ou para a página de suporte. Além disso, as informações técnicas foram organizadas de forma mais limpa utilizando listas.

---

## Novas Funcionalidades (Nesta Etapa)

*   **Imagens e Acessibilidade:** Uso da tag `<img>` contendo a imagem demonstrativa do PC Gamer em destaque, com os atributos `src`, `width` e o texto alternativo `alt` para garantir acessibilidade a leitores de tela.
*   **Links de Interação (CTA):** Implementação da tag `<a>` com os atributos `href` e `target="_blank"` criando botões para "Comprar via WhatsApp" e acessar o "Suporte".
*   **Periféricos Inclusos (Listas Não Ordenadas):** Uso de `<ul>` e `<li>` para listar os itens que acompanham o setup gamer com marcadores (bullets).
*   **Passo a Passo de Montagem (Listas Ordenadas):** Uso de `<ol>` e `<li>` para descrever o processo sequencial de montagem do equipamento.
